The local notebook

From a price check to a useful comparison.

Pantry Scout is a personal, non-commercial project, starting around McKinney, Texas. The local application supports Texas ZIP selection and filtering nearby saved stores.

01

Choose an area

Select a Texas ZIP code and review saved stores nearby. Coverage grows as observations are added.

02

Record the details

Save a product's brand, size, price, source, and observation time. Include promotion requirements when they apply.

03

Compare with context

Review prices for matching products and retain history. Import and export observations using CSV files.

Sources & availability

Every price needs context.

The local application supports Kroger API searches and scheduled refreshes for eligible saved items when connected. Other observations may be entered manually or collected from accessible official retailer listings.

Prices can differ by store, channel, package, promotion, and time. Online listings are distinguished from shelf prices. Stock remains unknown unless a source explicitly confirms availability.

Retailer coverage is incomplete. A saved observation is not a guarantee of today's price or inventory. Pantry Scout is an independent project; retailer names do not imply sponsorship, partnership, or API approval.
